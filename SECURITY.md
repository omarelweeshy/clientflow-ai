# Security reporting

This repository is a local demonstration MVP. Read [the threat model](docs/SECURITY.md) before considering a deployment. Only the latest default-branch revision is maintained; there is no production support or response-time commitment.

Please report vulnerabilities through the repository's **Security → Report a vulnerability** feature when available. If private reporting is unavailable, contact the maintainer through the GitHub profile to arrange a private channel. Do not post exploitable details, real enquiries, credentials or logs in public issues.

Include the affected revision, reproduction using fictional data, expected behavior, observed impact and a suggested mitigation if available. Never test against someone else's deployment without authorization.
